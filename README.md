# CS221 — Artificial Intelligence: Principles and Techniques

Stanford CS221 课程作业实现。**版本：Autumn 2025**

| 作业 | 主题 |
| --- | --- |
| `hw1_foundations` | 基础：用 NumPy / einops 实现向量化计算与优化相关基本操作 |
| `hw2_sentiment` | 文本分类：手写 Softmax 回归（前向、交叉熵、梯度推导与实现），词向量平均特征，并用 PyTorch 复现 |
| `hw3_route` | 路径规划：状态空间建模、一致代价搜索与 A\* 启发式 |
| `hw4_mountaincar` | 强化学习：MDP 建模、值迭代与 Q-learning（Mountain Car 环境） |
| `hw5_pacman` | 对抗搜索：Minimax、Alpha-Beta 剪枝、Expectimax 与评估函数设计 |
| `hw6_bayesian` | 概率推断：贝叶斯网络建模与推断 |
| `hw7_logic` | 逻辑：命题逻辑与一阶逻辑的形式化、推理与自然语言接口 |
| `hw8_society` | AI 与社会（书面作业） |
